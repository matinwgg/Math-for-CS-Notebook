# Math for Computer Science Notebook

A rigorous, implementation-oriented mathematics notebook for computer science, software engineering, cryptography, machine learning, and distributed systems.

## Topics

- Discrete mathematics and proof techniques
- Logic, sets, relations, and combinatorics
- Graph theory and algorithms
- Linear algebra for ML and graphics
- Probability and statistics
- Optimization and numerical methods
- Number theory and modular arithmetic
- Information theory
- Complexity theory
- Cryptographic mathematics

## Implementation track

The repository deliberately mixes mathematical exposition with executable implementations in **Python and Rust**. Each topic should contain definitions, worked derivations, computational experiments, and tests where practical.

## Goal

Build a reusable mathematical foundation for graduate-level computer science research rather than a collection of disconnected notes.
